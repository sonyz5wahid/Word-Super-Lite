# Roadmap Word Super Lite

## Milestone 0 — Prototype
- [x] Native Android Java project
- [x] Ribbon-like desktop shell
- [x] Basic text editing
- [x] Minimal DOCX text import/export

## Milestone 1 — Editing foundation
- [ ] Selection-aware bold, italic, underline
- [ ] Font family and font size
- [ ] Paragraph alignment and line spacing
- [ ] Undo/redo and find/replace
- [ ] Keyboard shortcut layer

## Milestone 2 — Page layout
- [ ] A4, F4, Letter
- [ ] Margins and orientation
- [ ] Page breaks and section breaks
- [ ] Header, footer and page numbers
- [ ] Multi-page rendering

## Milestone 3 — DOCX compatibility
- [ ] Preserve styles and runs
- [ ] Tables and images
- [ ] Hyperlinks and lists
- [ ] Footnotes and references
- [ ] Safe round-trip for unsupported OOXML parts

## Milestone 4 — Legacy-device optimization
- [ ] Test API 17 device
- [ ] Measure memory on 1.5 GB RAM
- [ ] Lazy page rendering
- [ ] Background save without UI stalls
